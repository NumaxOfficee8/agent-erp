# AgentERP Phase 1: 模組動態插拔與自訂 SVG 選單架構

在 Phase 0 中，我們成功驗證了雲端自動編譯與更新。
根據我們的決策，**Phase 1 的核心目標將「完全聚焦於：模組動態插拔與自訂 SVG 選單架構」的設計與實作。** 
其他安全與同步特性（如金鑰鑰匙圈、真實 LLM 串接、SQLite 資料庫加密）將移至後續階段計畫中。

---

## 1. Phase 1 核心功能規格

### 1.1. 獨立的模組設計 (Strict Module Decoupling)
* **設計目的**：每一個業務模組（例如：財務 BI 看板、CRM 客戶模組）都是完全獨立的代碼包。模組之間沒有狀態共享，互不干涉，降低系統複雜度並提高邊緣端的沙盒安全性。

### 1.2. 模組描述文件 (manifest.json)
每個模組的目錄中都會包含一個 `manifest.json` 設定檔，用來定義該模組的屬性，特別是它所使用的 SVG 圖示：
```json
{
  "id": "sales_bi",
  "name": "Finance BI 大看板",
  "iconSvg": "<svg width=\"18\" height=\"18\" viewBox=\"0 0 24 24\" fill=\"none\" stroke=\"currentColor\" stroke-width=\"2\" stroke-linecap=\"round\" stroke-linejoin=\"round\"><line x1=\"18\" y1=\"20\" x2=\"18\" y2=\"10\"></line><line x1=\"12\" y1=\"20\" x2=\"12\" y2=\"4\"></line><line x1=\"6\" y1=\"20\" x2=\"6\" y2=\"14\"></line></svg>",
  "entry": "sales_bi_module.js"
}
```

### 1.3. 動態側邊欄選單渲染 (Dynamic SVG Sidebar Menu)
* **選單解耦**：側邊欄導覽列將**完全移除所有硬編碼**的業務模組按鈕。
* **Svelte 動態渲染**：前端 Svelte 透過 `{#each appState.installedModules as mod}` 迴圈讀取安裝的模組，並透過 Svelte 的 `{@html mod.iconSvg}` 語法將模組宣告的 SVG 標籤字串動態渲染為選單圖示。
* **成果**：若未來在雲端或本地新增一個全新模組，只需將模組包下載解壓，側邊欄選單就會自動長出新項目，完全不需重新編譯或重構外殼程式。

### 1.4. 主視窗生命週期管理 (Workspace Outlets)
* 中間的主內容區域設計為動態掛載點（Outlet）。
* 切換選單時，動態加載該模組的 `entry` 程式，並在主視窗進行掛載（Mount）。
* 切換走時自動銷毀（Unmount）舊模組，釋放系統記憶體。
