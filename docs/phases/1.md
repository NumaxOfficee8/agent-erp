# AgentERP Phase 1: 核心邊緣安全與 LLM 真實對話串接計畫

在 Phase 0 中，我們成功建置了 Svelte 5 + Tauri v2 前後端骨架，並驗證了雲端自動編譯、數位簽章與全自動更新發佈。
**Phase 1 的核心目標是：「將原型中的模擬組件轉為生產等級的實體功能」，聚焦於「金鑰安全、真實 LLM 串流串接與 SQLite 邊緣加密」。**

> [!NOTE]
> **決策調整**：由於 Svelte 前端模組的動態熱更新已於 Phase 0 原型驗證完成，在 Phase 1 中我們將**不優先擴展或重構熱更新邏輯**，全面聚焦於本機作業系統鑰匙圈金鑰管理、真實大模型流式串接與 SQLite 資料庫加密。

---

## 1. Phase 1 四大核心功能規劃

### 1.1. 系統鑰匙圈 (OS Keychain) 安全金鑰管理 [真實實作]
* **設計目的**：用戶必須能夠「帶上自己的 API 金鑰 (BYOK)」。為防止 XSS 攻擊竊取金鑰，前端 JavaScript 記憶體絕不能接觸到明文金鑰，金鑰必須安全地儲存在作業系統的密碼庫中。
* **技術實作**：
  * 在 Rust 端引入 `keyring` 庫，直接對接 macOS 的 **Keychain Access (鑰匙圈)** 及 Windows **Credential Manager (憑證管理員)**。
  * **安全流程**：用戶在 UI 設定頁面輸入 Gemini / OpenAI / DeepSeek 金鑰 ➜ 透過 Tauri 安全 IPC 通道送入 Rust ➜ Rust 呼叫 OS API 寫入硬體級加密憑證庫中。

### 1.2. 真實 LLM 串流代理 (LLM Streaming Proxy) [真實實作]
* **設計目的**：將目前的模擬對話框替換成能夠與真實大語言模型通訊的 AI 智能助理。
* **技術實作**：
  * 在 Rust 端整合 `genai` 庫或直接整合各模型的 HTTP Client（如 Google Gemini API, OpenAI API）。
  * **流式接收**：當用戶發送對話時，Rust 從 OS 鑰匙圈取出 API Key，向雲端模型發起 HTTPS 請求，並透過 Tauri `Channel` 將接收到的 SSE (Server-Sent Events) 字元串流即時推送給前端 Svelte，實現流暢的 Token 逐字打字效果。

### 1.3. 邊緣資料庫加密防禦 (SQLCipher Integration) [安全防禦]
* **設計目的**：作為「邊緣安全工作站」，本地儲存的 SQLite 訂單數據、日誌及緩存絕不能以明文形式存在，否則一旦電腦遺失，企業機密將被直接讀取。
* **技術實作**：
  * 將 Rust 後端 `rusqlite` 依賴升級，開啟 `bundled-sqlcipher` 特性（或使用 `sqlx` 搭配 SQLCipher 綁定）。
  * 每次應用程式啟動時，使用本機硬體產生的主金鑰（Master Key，儲存於 OS Keychain 中）對本地 SQLite 進行加密解密。硬碟上的 `.db` 檔將以 **AES-256 加密密文**形式儲存。

### 1.4. 本地與雲端增量雙向同步協議 (Incremental Sync Protocol) [核心業務]
* **設計目的**：實作「本地優先 (Local-First)」的雙向同步機制，保證離線時可正常點單，連線時自動上傳本地異動並下載雲端新訂單。
* **技術實作**：
  * 在 SQLite 中建立 `sync_queue` 暫存表，記錄本地尚未同步的變更交易。
  * 設計基於時間戳（Timestamp）與客戶端 ID（Client ID）的輕量級衝突解決邏輯，實現與雲端資料庫伺服器的增量雙向同步。

### 1.5. 動態模組插拔與自訂 SVG 選單架構 (Pluggable Module & Custom SVG Menu) [核心架構]
* **設計目的**：徹底將「外殼框架」與「業務模組」解耦。模組與模組之間完全獨立運作，互不干涉，且各個模組可以完全自訂側邊欄選單的 SVG 圖示與顯示名稱，實現真正的插件化平台。
* **技術實作**：
  * **描述文件設計**：模組宣告清單中包含 `manifest.json`，其中設定 `"iconSvg"` 欄位直接儲存該模組選單的 SVG 標籤字串（例如：`<svg...>...</svg>`）。
  * **動態選單渲染**：Svelte 前端側邊欄移除所有硬編碼的業務選單項目，改用 `{#each appState.installedModules as mod}` 迴圈讀取安裝的模組，並以 `{@html mod.iconSvg}` 來動態渲染每個模組自訂的 SVG 圖示。
  * **主視窗生命週期**：當切換選單時，主區域動態掛載/卸載對應模組的 Svelte Component（或 iframe 頁面），並銷毀舊模組以釋放記憶體。
